## Project Overview
**Quizzy** is a modern, responsive, and visually engaging client-side web application designed to test and expand user knowledge across multiple categories. Built with a vivid violet-indigo gradient aesthetic, it allows users to participate in single-category or randomized quizzes, select difficulty levels, answer timed multiple-choice questions, and analyze their performance with detailed score summaries and question explanations.

## Project Scope
This project focuses on designing and developing a complete frontend interactive quiz engine featuring:
- A clean, header-driven interface displaying live global best score tracking via browser `localStorage`.
- An engaging Welcome landing screen with interactive features highlights.
- A comprehensive Quiz Configuration screen with mode selection (Category-Based vs. Random Mixed), subject picking, difficulty levels, and question count selection.
- Dynamic question screens featuring countdown timers with low-time warning animations, real-time progress bar tracking, and instant answer feedback.
- Automatic option shuffling and selection locking to guarantee unbiased scoring.
- An animated performance results dashboard with a radial progress ring, metric breakdown cards, and localized high score updates.
- An itemized Answer Review screen displaying chosen answers, correct answers, status badges, and educational explanations.
The application operates entirely within the browser without external backend dependencies or API reliance.

## Technologies Used
- **HTML5:** For structured layout, dynamic screen routing, semantic elements, and accessible buttons.
- **CSS3:** For modern gradients, custom properties, responsive flexbox/grid layouts, SVG icons, keyframe animations, and backdrop filters.
- **Vanilla JavaScript (ES6+):** For state management, interval timer handling, array shuffling algorithms, dynamic DOM rendering, and `localStorage` integration.

## Features
- Ultra-modern violet/indigo themed user interface with smooth transitions and micro-animations.
- 100% responsive layout optimized for desktop, tablet, and mobile screens without horizontal scrolling.
- Dual quiz modes: Category-Based (single subject focus) and Random Mixed (cross-category sampling).
- 6 diverse subjects: General Knowledge, Science, Technology, Programming, Sports, and Geography.
- 3 difficulty levels (Easy: 20s, Medium: 15s, Hard: 10s) with custom countdown timers per question.
- Flexible question count selection (5, 10, or 15 questions per session).
- Comprehensive question bank containing 90+ verified, non-duplicate questions.
- Automatic answer shuffling that retains accurate answer-key mapping.
- Instant visual feedback (green for correct, red for incorrect) and explanatory breakdowns.
- Local high score persistence using browser `localStorage` without tracking personal data.
- Complete navigation freedom allowing users to restart, change configurations, or return home at any time.

## How to Run the Project
1. Clone or download this repository.
2. Open the project folder (`Quizzy`) in Visual Studio Code.
3. Open `index.html` directly in any modern web browser (Chrome, Edge, Firefox, Safari).
Alternatively, open the project folder in Visual Studio Code, right-click `index.html`, and select **Open with Live Server**.
